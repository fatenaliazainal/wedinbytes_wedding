IMPORTANT: We now have a new confirmed production issue.

A YouTube video that passes our validation successfully is still showing:

"YouTube Error 153 — Video player configuration error"

Screenshot confirms the actual embedded player is failing with Error 153.

According to the official YouTube IFrame Player API documentation, error 153 means the request does not include the HTTP Referer header or equivalent API client identification.

Official documentation:
https://developers.google.com/youtube/iframe_api_reference

DO NOT replace the YouTube video.
DO NOT blame the video.
The video has already passed our validation and the actual problem is the embed request configuration.

==================================================
1. FIX ERROR 153
==================================================

Inspect the production application headers and identify whether Referrer-Policy is suppressing the HTTP Referer header.

Search the entire project for:

Referrer-Policy
referrer-policy
no-referrer
same-origin
origin
noreferrer
<meta name="referrer">
Content-Security-Policy

The YouTube documentation recommends:

Referrer-Policy: strict-origin-when-cross-origin

Make sure our production site does NOT use:

Referrer-Policy: no-referrer

or any configuration that prevents the Referer header from being sent to YouTube.

Also make sure we are not using:

noreferrer

when opening/creating the YouTube player.
