Perform a full production-ready security and architecture audit of the entire WedInBytes codebase.

IMPORTANT:
- Do NOT rewrite the application.
- Do NOT change UI or business logic unless required.
- Preserve all existing functionality.
- Only make safe production improvements.
- Before changing any file, understand how it is connected to the rest of the system.

==================================================
1. INVITATION OWNERSHIP (CRITICAL)
==================================================

Audit every API endpoint that modifies an invitation.

Ensure every write operation verifies:

- session exists
- invitation exists
- invitation.userId === session.userId

Admin users may bypass this check.

Never allow buyers to modify another buyer's invitation even if they know the token.

Check ALL routes including but not limited to:

PATCH invitation
DELETE invitation
gallery upload
logo upload
music update
language update
design override
RSVP settings
cover settings
all future write endpoints

Create reusable middleware/helper if appropriate.

3. PUBLIC RSVP SECURITY
==================================================

Review:

GET /api/rsvp
