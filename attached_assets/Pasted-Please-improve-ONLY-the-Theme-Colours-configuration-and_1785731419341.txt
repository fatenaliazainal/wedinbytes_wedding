Please improve ONLY the Theme Colours configuration and color mapping.

IMPORTANT:
Do NOT redesign the invitation.
Do NOT change layouts, spacing, typography, fonts, animations, components, content, or existing visual structure.

The purpose of this change is to make the Theme Colours editor easier for Admin to understand and to allow SECTION TITLES to have a different color from BODY/DETAIL TEXT.

Before changing anything:
1. Inspect the existing theme color architecture.
2. Reuse existing color variables/fields wherever possible.
3. Preserve all existing saved theme colors.
4. Only add a new color field if the required color role does not currently exist.

THEME COLOURS


1. TYPOGRAPHY

A. Main Names
Helper:
"Couple names & featured script text"

Example preview:
Ahmad & Siti

Controls:
- Couple names
- Main featured/script names only

IMPORTANT:
Do not automatically apply this to section headings.


B. Section Titles
Helper:
"Titles for each invitation section"

Example preview:
EVENT PROGRAMME

This must control section headings such as:
- Event Programme
- Our Story
- Gallery
- RSVP
- Gift Registry
- Wishes
- Contact
- Location
- Accommodation
- and equivalent section headings used by the invitation

IMPORTANT:
Section Titles MUST have its own independent color.

Changing Section Titles must NOT change:
- body text
- programme details
- dates/descriptions
- couple names
- buttons


C. Content Text
Helper:
"Main details, dates & body content"

Example preview:

11:00 AM
Guest Arrival

This should control normal content/details inside sections.

Examples:
- Event programme time
- Event programme event name
- Wedding details
- Dates
- Venue details
- Paragraphs
- Main descriptions
- Other normal body content

IMPORTANT:
This must be independent from Section Titles.


D. Muted / Small Text
Helper:
"Captions, notes & secondary information"

Example preview:
Kindly arrive 15 minutes early

Use for existing secondary/subtle text where appropriate, such as:
- captions
- small supporting labels
- secondary descriptions
- notes

Do NOT arbitrarily change text that currently has a deliberate special style.
Reuse the existing secondary/muted text mapping if one already exists.

BACKWARD COMPATIBILITY
--------------------------------------------------

VERY IMPORTANT:

Existing themes and saved invitations must NOT visually break.

If "Section Titles" is a NEW theme color field:

- Add it safely to the existing theme configuration/schema.
- Existing invitations without this value must fall back to the most appropriate CURRENT heading/text color.
- Do not make existing saved invitations suddenly change appearance.
- Do not require old invitations to be manually updated.

Use a fallback such as:

sectionTitleColor =
savedSectionTitleColor
?? existingHeadingColor
?? existingPrimaryTextColor

Adapt this to the actual existing architecture instead of blindly using these variable names.


If "Muted / Small Text" requires a new field, follow the same backward-compatible fallback principle.
