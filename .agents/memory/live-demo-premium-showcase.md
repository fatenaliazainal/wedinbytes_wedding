---
name: Live Demo Premium showcase
description: Rules for keeping the public demo attractive and representative of the Premium package
---

The public Live Demo is intentionally assigned to the real Premium package and should contain safe, non-customer showcase data for every Premium feature: RSVP/Wishes, Contact, Location, Calendar, Countdown, Music, Gallery, Money Gift and Dress Code.

**Why:** The demo is a sales experience; an empty or Standard-gated demo hides the features customers are deciding whether to purchase.

**How to apply:** Keep demo seeding idempotent and scoped only to token `demo`. Use local demo assets and clearly mark payment artwork as non-payment; never copy customer-owned gallery or QR assets into the demo.
