---
name: Admin UI density
description: Visual constraint for Admin dashboard refinements
---

Admin visual refinements should preserve the existing website typography, color tokens, interactions, routes, and data flows. The preferred direction is a white, compact, information-dense workspace: wider content, smaller labels, tighter tabs, reduced card padding, and denser tables. Revenue reporting should use expandable month rows with daily details and totals.

**Why:** The owner wants the Admin surface to match a compact operational reference without changing the established Wedinstudio visual identity or behavior.

**How to apply:** Keep presentation-only changes scoped to Admin UI classes and structure; revenue aggregation may extend the existing admin stats response but must remain based on persisted order/payment data. Do not replace fonts, introduce a new visual system, or alter navigation, modal, or status-action behavior.
