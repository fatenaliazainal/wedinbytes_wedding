---
name: Admin UI density
description: Visual constraint for Admin dashboard refinements
---

Admin visual refinements should preserve the existing website typography, color tokens, interactions, routes, and data flows. The preferred direction is a compact, information-dense layout: wider content, smaller labels, tighter tabs, reduced card padding, and denser tables.

**Why:** The owner wants the Admin surface to match a compact operational reference without changing the established Wedinstudio visual identity or behavior.

**How to apply:** Keep presentation-only changes scoped to Admin UI classes and structure; do not replace fonts, introduce a new visual system, or alter API, navigation, modal, or status-action behavior.
