---
name: Catalog preview style
description: Visual treatment for the public wedding-card catalog previews.
---

The public catalog uses direct portrait invitation previews without a phone frame or outer white border; each card uses a soft shadow while the design name, code, and action remain outside the preview.

**Why:** The catalog should resemble physical invitation cards and match the reference presentation rather than looking like phone mockups.

**How to apply:** Keep the preview container portrait with a transparent background and subtle shadow, and preserve the existing live-demo and editor actions.
