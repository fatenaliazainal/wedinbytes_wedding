---
name: Cover-name invitation links
description: Public invitation URLs use the customer-facing Cover Groom Name and Cover Bride Name consistently across account types and email.
---

Public invitation URLs must use `Cover Groom Name` followed by `Cover Bride Name`. Only invitations without those values may fall back to short names, full names, or initials.

**Why:** The URL is a guest-facing part of the invitation and should match the names shown on the cover, not expose the couple's full database names or an unrelated short-name field.

**How to apply:** Keep frontend link builders, server public-slug lookup, Buyer and Business Account dashboard responses, Admin links, and payment emails aligned. Continue accepting the previous named slug as a lookup alias so existing shared links remain usable.
