---
name: Customer tutorial placement
description: Where the How To Use guide belongs and how it should be delivered.
---

The customer-facing “How To Use” guide belongs on the public website as global help content, not inside the invitation editor.

**Why:** The guide is intended for anyone learning the product and should remain separate from invitation-specific editing, saving, package visibility, and customer data.

**How to apply:** Keep the tutorial independently routable from the public website navigation. Treat its PDF/link as global content rather than adding it to an invitation record or editor save payload.
